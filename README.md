# Prisma Cursos 🏴‍☠️

Projeto desenvolvido pelo **Grupo 2** como parte do **processo trainee da Orc’estra**, utilizando **HTML, CSS e JavaScript, sem frameworks**.

A Prisma Cursos é uma proposta de site de cursos com temática pirata, combinando aprendizado, tecnologia e exploração.

> 🚧 Projeto em desenvolvimento.

## Objetivo

Transformar o protótipo desenvolvido no Figma em um site responsivo, aplicando conhecimentos de desenvolvimento front-end e trabalho em equipe.

O projeto envolve:

- Estruturação de páginas com HTML semântico.
- Estilização e responsividade com CSS.
- Implementação de interações com JavaScript.
- Versionamento e colaboração com Git e GitHub.

## Protótipo

O layout e a identidade visual têm como referência o protótipo desenvolvido no Figma:

[Acessar o protótipo no Figma](https://www.figma.com/design/sA4WehhMqD8b2tzQaybbxv/Prot%C3%B3tipo?node-id=0-1)

## Páginas previstas

- **Início:** apresentação da Prisma Cursos e destaques.
- **Cursos:** catálogo dos cursos disponíveis.
- **Páginas individuais dos cursos:**
  - After Effects.
  - Empreendedorismo.
  - Gestão.
  - Marketing.
  - Python.
- **Quem Somos:** apresentação da empresa.
- **Depoimentos:** relatos de alunos.
- **Formulário:** página destinada ao preenchimento de informações pelo usuário.

As páginas e suas interações serão implementadas ao longo do desenvolvimento.

### Organização

- `assets/`: imagens, ícones e fontes utilizados no projeto.
- `css/css_pages/`: estilos específicos de cada página.
- `js/`: scripts responsáveis pelas interações.
- `pages/`: páginas HTML internas.
- `index.html`: página inicial do site.
- `README.md`: documentação do projeto.

Estilos compartilhados entre as páginas poderão ser centralizados em `css/global.css`.

## Como executar

O projeto não exige instalação de dependências para sua estrutura atual.

1. Clone o repositório:

   ```bash
   git clone https://github.com/Bercacos/prisma-cursos-grupo-2.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd prisma-cursos-grupo-2
   ```

3. Abra o arquivo `index.html` no navegador.

Também é possível baixar o repositório em **Code → Download ZIP**, extrair os arquivos e abrir o `index.html`.

## Padrões de desenvolvimento

- Utilizar nomes de arquivos em minúsculas, sem acentos e separados por hífens.
- Separar a estrutura HTML, a estilização CSS e os comportamentos JavaScript.
- Utilizar caminhos relativos para acessar arquivos do projeto.
- Priorizar HTML semântico e acessibilidade.
- Adaptar as páginas para celular, tablet e desktop.
- Fazer commits com mensagens claras sobre as alterações.
- Atualizar a documentação conforme o desenvolvimento.
